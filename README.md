# 💡 idea-to-code-bot

Telegram-бот, который превращает идею в рабочий код через Claude API.

Описываешь задумку текстом → бот строит план → задаёт уточняющие вопросы → распределяет работу по «отделам» → генерирует файлы → отдаёт ZIP-архив с готовым кодом.

---

## Как это работает

```
Идея (текст)
    ↓
Claude: строит план (краткий + развёрнутый)
    ↓
Бот находит точки принятия решений → кнопки выбора
    ↓
Распределение по отделам: CODE / DESIGN / MUSIC / CONTENT
    ↓
Каждый отдел выполняется через отдельный промпт в Claude
    ↓
Файлы собираются в ZIP → отдаётся пользователю
```

---

## Демо

**Запрос:** «Сделай мне змейку на Python с рекордами»

**Бот:**
1. Строит план: игровой цикл, отрисовка, хранение рекордов
2. Спрашивает: «Pygame или Tkinter?» → выбираешь кнопкой
3. Отдел CODE пишет `game.py`, отдел CONTENT пишет `README.md`
4. Возвращает `snake_game.zip`

---

## Ключевые технические решения

**Многослойные промпты**
Каждый этап — отдельный промпт с чёткой ролью: планировщик, арбитр решений, исполнитель отдела. Это предотвращает галлюцинации и держит контекст чистым.

**FSM + кнопки**
Состояние диалога хранится через aiogram FSM. Кнопки восстанавливают контекст при перезапуске бота.

**Прокси для Claude API**
Telegram API блокируется с российских IP → VPN в TUN-режиме. Claude API через proxyapi.ru.
